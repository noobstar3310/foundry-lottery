# Foundry Smart Contract Lottery

A provably fair, decentralized lottery system built with Foundry and Chainlink VRF.

## What You'll Learn

1. **Foundry Development**

   - Setting up a Foundry project
   - Writing and running tests with Forge
   - Using Foundry's powerful testing utilities
   - Working with Foundry scripts for deployment

2. **Smart Contract Development**

   - Implementing a secure lottery system
   - Following Solidity best practices and patterns
   - Proper contract structuring and documentation
   - Gas optimization techniques

3. **Chainlink Integration**

   - Using Chainlink VRF (Verifiable Random Function) v2.5
   - Implementing Chainlink Automation for automated draws
   - Managing Chainlink subscriptions and callbacks

4. **Advanced Solidity Concepts**

   - Custom error handling
   - Events and logging
   - Enums and state management
   - Modular contract design
   - Secure fund handling

5. **Testing Best Practices**

   - Unit testing with Foundry
   - Test modifiers and fixtures
   - Mocking external contracts
   - Testing events and state changes
   - Chain-specific test modifications

6. **Security Considerations**
   - Implementing checks-effects-interactions pattern
   - Handling edge cases
   - Protecting against common vulnerabilities
   - Proper access control
